# 현장 이슈 대응 플레이북

이 문서는 실제 행사장에서 자주 나오는 문제를 빠르게 해결하기 위한 절차서입니다.

## 기본 원칙

- 사용자를 먼저 `현장 대응 센터`에서 찾습니다.
- 계정 정보가 맞는지 확인합니다.
- 문제 유형에 따라 `정보 수정`, `비밀번호 초기화`, `여분 팔찌 교체`를 사용합니다.

## 1. QR이 지워지거나 스캔이 안 된다

가장 흔한 대응입니다.

### 권장 절차

1. 관리자 대시보드에서 사용자를 검색합니다.
2. 본인 확인 후 `여분 팔찌로 교체`를 누릅니다.
3. 비밀번호까지 잊어버렸다면 `비밀번호도 함께 초기화`를 체크합니다.
4. 사용 가능한 guest 여분 팔찌를 선택합니다.
5. 교체를 실행합니다.
6. 바로 열린 새 QR을 스캔하게 합니다.

### 결과

- 기존 팔찌 QR은 더 이상 로그인되지 않습니다.
- 새 guest 팔찌가 해당 사용자의 로그인 팔찌가 됩니다.

## 2. 비밀번호를 잊어버렸다

### QR은 살아 있는 경우

1. 사용자를 검색합니다.
2. `비밀번호 초기화`를 누릅니다.
3. 사용자가 기존 QR을 다시 스캔하게 합니다.
4. 회원가입 화면에서 새 비밀번호를 설정하게 합니다.

### QR도 같이 문제인 경우

1. `여분 팔찌로 교체`를 누릅니다.
2. `비밀번호도 함께 초기화`를 체크합니다.
3. 여분 팔찌를 선택합니다.
4. 새 QR로 다시 접속하게 합니다.

## 3. 이름이 틀리다 / 등록 이름이 맞지 않는다

현재 로직상, 이미 이름이 있는 계정은 가입 화면에서 이름을 직접 고치기 어렵습니다.

### 절차

1. 사용자를 검색합니다.
2. `사용자 정보 수정`을 누릅니다.
3. 이름과 필요하면 동아리/역할을 수정합니다.
4. 저장합니다.

### 추가 메모

- 이미 로그인된 사용자 화면은 즉시 바뀌지 않을 수 있습니다.
- 수정 후 다시 로그인해야 이름이 화면에 반영됩니다.

## 4. 등록이 안 되어 있다

### 절차

1. 관리자 대시보드의 `사용자 생성`에서 새 계정을 만듭니다.
2. 역할을 선택합니다.
3. 필요하면 동아리를 입력합니다.
4. 생성 직후 열린 QR을 사용자에게 보여줍니다.

### 역할 선택 기준

- 기명 참가자면 `user`
- 무기명 참가자거나 여분 팔찌면 `guest`
- 운영진이면 `admin`

## 5. 무기명 팔찌 여유분에 이름 데이터를 기입해서 바꿔줘야 한다

이 요구는 보통 두 경우로 나뉩니다.

### 경우 A. 기존 사용자 계정을 새 무기명 팔찌에 옮기고 싶다

가장 권장되는 방법입니다.

1. 기존 사용자를 검색합니다.
2. `여분 팔찌로 교체`를 누릅니다.
3. 여분 guest 팔찌를 선택합니다.
4. 필요하면 비밀번호도 같이 초기화합니다.

이 방식의 장점:

- 기존 역할, 이름, 동아리, 투표 이력이 그대로 유지됩니다.
- 단순히 이름만 베끼는 것이 아니라 실제 계정을 새 팔찌에 연결합니다.

### 경우 B. 무기명 guest 팔찌 자체의 이름만 바꾸고 싶다

예를 들어 방문객 이름을 현장에서 적어 넣어야 하는 상황입니다.

1. 해당 guest 계정을 검색합니다.
2. `사용자 정보 수정`을 누릅니다.
3. 이름을 바꿉니다.
4. 저장합니다.

## 6. 운영 시작 전 체크리스트

행사 전에 아래를 꼭 확인하세요.

1. 관리자 계정으로 `/login?uuid=<ADMIN_UUID>` 접속이 되는지 확인
2. 여분 guest 팔찌 계정이 충분한지 확인
3. QR 보기와 링크 복사가 정상 동작하는지 확인
4. 비밀번호 초기화 후 가입 화면으로 제대로 이동하는지 확인
5. 인터넷이 느릴 때도 관리자 화면에서 사용자 검색이 되는지 확인

## 7. 현장에서 절대 헷갈리지 않는 요약

- QR 문제: `여분 팔찌로 교체`
- 비밀번호 문제: `비밀번호 초기화`
- 이름/동아리 문제: `사용자 정보 수정`
- 등록 누락: `사용자 생성`
