# 행사 마무리 정리

이 문서는 행사 종료 후 운영자가 결과를 정리할 때 참고하는 문서입니다.

## 먼저 저장할 파일 2개

행사가 끝나면 보통 아래 두 파일을 먼저 저장하면 됩니다.

1. `종합 결과 (XLSX)`
2. `사용자별 내역 (XLSX)`

이 두 파일만 있어도 기본적인 결과 정리는 가능합니다.

## 1. 전체 투표 결과 다운로드

관리자 페이지 상단의 `종합 결과 (XLSX)` 버튼을 누르면 게임별 결과 파일을 저장할 수 있습니다.

포함 내용:

- 게임 이름
- 참가 부문
- 기준별 점수
- 금/은/동 개수
- 총점

## 2. 사용자별 투표 내역 다운로드

관리자 페이지 상단의 `사용자별 내역 (XLSX)` 버튼을 누르면 사용자 기준 기록을 저장할 수 있습니다.

포함 내용:

- 사용자별 총 투표 수
- 본인 동아리 투표 수
- 전체 상세 내역

이 파일은 행사 운영 검토나 이상 데이터 확인이 필요할 때 특히 유용합니다.

## 3. 결과 파일 정리 팁

- 행사 날짜를 파일명이나 폴더명에 같이 적어두기
- 최종본은 별도 백업 폴더에 보관하기
- 필요하면 기획팀 공유용과 내부 검토용 파일을 나눠두기

예시:

- `2026-unicon-종합결과.xlsx`
- `2026-unicon-사용자별내역.xlsx`

## 4. 마무리 체크리스트

이 네 가지가 끝나면 행사 마감 작업은 기본적으로 완료된 상태입니다.

1. 종합 결과 XLSX 저장
2. 사용자별 내역 XLSX 저장
3. 필요하면 계정 리스트 XLSX도 함께 보관
4. 결과 파일을 운영진 저장소나 공유 드라이브에 백업
