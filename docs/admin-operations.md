# 관리자 대시보드 사용법

관리자 대시보드는 행사 준비부터 현장 대응, 행사 마무리까지 한 화면에서 처리할 수 있도록 만든 운영 화면입니다.

## 이 문서가 필요한 순간

아래 중 하나에 해당하면 이 문서를 먼저 보면 됩니다.

- 관리자 화면에 어떤 기능이 있는지 한 번에 알고 싶을 때
- 행사 전에 어디서 무엇을 등록해야 하는지 헷갈릴 때
- 현장에서 어떤 버튼을 눌러야 할지 빠르게 찾고 싶을 때

## 이 화면에서 할 수 있는 것

- 사용자 검색
- QR 보기
- 로그인 링크 복사
- 사용자 정보 수정
- 비밀번호 초기화
- 여분 팔찌 교체
- 사용자 생성
- 계정 리스트 XLSX 다운로드
- 게임 등록 / 수정 / 삭제
- 게임 썸네일 업로드
- 전체 투표 결과 XLSX 다운로드
- 사용자별 투표 내역 XLSX 다운로드

## 화면 구성 요약

### 1. 상단 버튼

- `계정 리스트 (XLSX)`: 팔찌 발주용 계정 목록 저장
- `종합 결과 (XLSX)`: 게임별 최종 결과 저장
- `사용자별 내역 (XLSX)`: 사용자별 투표 기록 저장

행사 전에는 `계정 리스트`, 행사 후에는 `종합 결과`와 `사용자별 내역` 버튼을 가장 자주 쓰게 됩니다.

### 2. 통계 카드

- 현재 투표 참여자 수
- 비밀번호 설정 완료 수
- 여분 팔찌 후보 수
- 등록된 게임 수

### 3. 현장 대응 센터

가장 자주 쓰는 영역입니다.

- 사용자 검색
- 선택한 사용자 상세 정보 확인
- QR 확인
- 로그인 링크 복사
- 정보 수정
- 비밀번호 초기화
- 여분 팔찌 교체

현장 문제 대부분은 여기서 해결됩니다.

### 4. 사용자 생성

등록 누락 참가자나 guest 여분 팔찌를 바로 만들 수 있습니다.

행사 전에는 여분 guest 계정을 미리 많이 만들어 두고, 행사 중에는 등록 누락 인원을 여기서 추가하면 됩니다.

### 5. 게임/썸네일 준비

행사 시작 전에 게임 정보와 썸네일을 입력하거나 수정하는 영역입니다.

게임 제목, 설명, 참가 부문, 개발자 목록, 썸네일을 여기서 관리합니다.

### 6. 전체 사용자 목록 / 등록된 게임

행사 전 검수나 행사 중 일괄 확인이 필요할 때 사용합니다.
