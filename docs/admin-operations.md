# 관리자 대시보드 사용법

관리자 대시보드는 행사장에서 바로 대응할 수 있게 다음 기능을 제공합니다.

- 사용자 검색
- QR 다시 보여주기
- 로그인 링크 복사
- 사용자 정보 수정
- 비밀번호 초기화
- 여분 팔찌로 교체
- 사용자 생성
- 게임 관리
- 게임 썸네일 업로드
- 결과 XLSX 다운로드

## 화면 구성

### 1. 상단 안내

- QR 접속 후 실제로 어떤 분기가 일어나는지 짧게 요약해둔 영역입니다.
- 처음 보는 운영자도 여기만 읽으면 기본 흐름을 잡을 수 있게 만들었습니다.

### 2. 통계 카드

- 현재 투표 참여자 수
- 비밀번호 설정 완료 수
- 여분 팔찌 후보 수
- 등록된 게임 수

여기서 말하는 `여분 팔찌 후보`는 다음 조건을 만족하는 계정입니다.

- `guest`
- 비밀번호가 없음

## 현장 대응 센터

가장 많이 쓰는 영역입니다.

### 검색

- 이름
- UUID
- 역할
- 동아리

기준으로 검색할 수 있습니다.

### 선택한 사용자 카드

선택한 사용자에 대해 다음 정보를 보여줍니다.

- 이름
- 역할
- 현재 상태
- UUID
- 소속
- 로그인 링크

그리고 아래 액션을 바로 실행할 수 있습니다.

- `QR 보기`
- `로그인 링크 복사`
- `사용자 정보 수정`
- `비밀번호 초기화`
- `여분 팔찌로 교체`

## 사용자 정보 수정

이 기능은 아래 상황에서 사용합니다.

- 이름 오기입
- 동아리 오기입
- guest/user/admin 역할 수정 필요
- 무기명 팔찌의 표시 이름을 현장에서 바꿔야 할 때

주의:

- 이미 로그인된 사용자의 화면은 즉시 바뀌지 않을 수 있습니다.
- JWT에는 로그인 시점의 이름/역할이 들어가므로, 수정 후에는 다시 로그인해야 반영됩니다.

## 비밀번호 초기화

이 기능은 "비밀번호를 새로 지정"하는 기능이 아니라, 현재 비밀번호를 제거하는 기능입니다.

운영자는 아래처럼 이해하면 됩니다.

- 현재 비밀번호 삭제
- 다음 QR 접속 시 회원가입 화면으로 이동
- 그 자리에서 새 비밀번호 설정

따라서 아래 상황에 적합합니다.

- 비밀번호를 잊어버린 경우
- 본인 확인 후 다시 세팅하게 해야 하는 경우

## 여분 팔찌로 교체

이 기능은 현장 운영에서 가장 중요한 복구 기능입니다.

### 언제 쓰나

- QR이 지워져 스캔이 안 될 때
- 팔찌가 훼손되어 새 팔찌로 바꿔줘야 할 때
- 기존 팔찌 대신 무기명 여분 팔찌로 교체해야 할 때

### 동작 방식

서버는 대상 사용자의 `uuid`를 여분 `guest` 팔찌의 `uuid`로 바꿉니다.

즉:

- 새 팔찌 QR이 이제 그 사용자의 로그인 QR이 됩니다.
- 기존 QR은 더 이상 로그인에 쓸 수 없습니다.

### 여분 팔찌로 쓸 수 있는 조건

관리자 화면에는 아래 조건을 만족하는 guest 계정만 여분 후보로 표시됩니다.

- `guest` 역할
- 비밀번호 없음
- 투표 이력 없음

### 비밀번호도 같이 초기화

교체 창에서 체크하면 다음까지 함께 처리합니다.

- 새 팔찌로 교체
- 비밀번호 삭제

추천 상황:

- QR도 망가졌고 비밀번호도 잊어버린 경우

## 사용자 생성

등록 누락이나 현장 추가 참가자가 생기면 여기서 생성합니다.

### 생성 후 할 일

- 생성 직후 QR 모달이 열립니다.
- 바로 스캔하게 하거나 링크를 복사해서 전달하면 됩니다.

### 역할 선택 팁

- `user`: 기명 참가자
- `guest`: 무기명 팔찌 / 방문객 / 여분 팔찌
- `admin`: 운영진

## 게임/썸네일 준비

행사 시작 전에 가장 많이 쓰는 섹션입니다.

할 수 있는 일:

- 새 게임 등록
- 기존 게임 수정
- 썸네일 URL 직접 입력
- 스토리지 연결 시 썸네일 파일 업로드

### 권장 순서

1. 게임 이름 입력
2. 설명 입력
3. 참가 부문 선택
4. 개발자 목록 입력
5. 썸네일 URL 입력 또는 파일 업로드
6. 미리보기 확인
7. 저장

### 파일 업로드가 안 되는 경우

대부분 아래 원인입니다.

- 서버에 S3 관련 환경변수가 없음
- 버킷 또는 공개 URL 설정이 맞지 않음

이 경우에는 썸네일 URL 직접 입력 방식으로도 운영할 수 있습니다.

## 결과 다운로드

### 종합 결과 (XLSX)

- 게임별 총점
- 기준별 금/은/동 개수

### 사용자별 내역 (XLSX)

- 사용자별 총 투표 수
- 본인 동아리 투표 수
- 전체 상세 내역

## 운영 팁

- 여분 팔찌는 행사 전에 `무기명-01`, `무기명-02` 식으로 미리 guest 계정으로 만들어 두는 것을 권장합니다.
- QR 문제 대응은 보통 `사용자 검색` → `여분 팔찌로 교체` 순서가 가장 빠릅니다.
- 비밀번호 분실만 문제라면 팔찌 교체보다 `비밀번호 초기화`가 먼저입니다.
