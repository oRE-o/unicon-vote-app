# 관리자 대시보드 사용법

관리자 대시보드는 행사 준비부터 현장 대응, 행사 마무리까지 한 화면에서 처리할 수 있도록 만든 운영 화면입니다.

## 이 화면에서 할 수 있는 것

- 사용자 검색
- QR 보기
- 로그인 링크 복사
- 사용자 정보 수정
- 비밀번호 초기화
- 여분 팔찌 교체
- 사용자 생성
- 계정 리스트 XLSX 다운로드
- 게임 등록 / 수정 / 삭제
- 게임 썸네일 업로드
- 전체 투표 결과 XLSX 다운로드
- 사용자별 투표 내역 XLSX 다운로드

## 화면 구성 요약

### 1. 상단 버튼

- `계정 리스트 (XLSX)`: 팔찌 발주용 계정 목록 저장
- `종합 결과 (XLSX)`: 게임별 최종 결과 저장
- `사용자별 내역 (XLSX)`: 사용자별 투표 기록 저장

### 2. 통계 카드

- 현재 투표 참여자 수
- 비밀번호 설정 완료 수
- 여분 팔찌 후보 수
- 등록된 게임 수

### 3. 현장 대응 센터

가장 자주 쓰는 영역입니다.

- 사용자 검색
- 선택한 사용자 상세 정보 확인
- QR 확인
- 로그인 링크 복사
- 정보 수정
- 비밀번호 초기화
- 여분 팔찌 교체

### 4. 사용자 생성

등록 누락 참가자나 guest 여분 팔찌를 바로 만들 수 있습니다.

### 5. 게임/썸네일 준비

행사 시작 전에 게임 정보와 썸네일을 입력하거나 수정하는 영역입니다.

### 6. 전체 사용자 목록 / 등록된 게임

행사 전 검수나 행사 중 일괄 확인이 필요할 때 사용합니다.
