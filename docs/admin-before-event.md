# 행사 전 관리자 준비

이 문서는 행사 시작 전에 운영자가 반드시 확인해야 하는 준비 항목을 모아둔 문서입니다.

## 1. 서버와 관리자 접속 확인

먼저 아래 3가지를 확인하세요.

1. 메인 주소가 열리는지
2. 관리자 로그인 URL이 열리는지
3. 관리자 페이지 `/admin`이 보이는지

서버 터미널에서는 아래 명령으로도 확인할 수 있습니다.

```bash
univote status
```

## 2. 관리자 계정 접속 방법

관리자도 일반 로그인 화면을 사용합니다.

1. `http://SERVER_IP/login?uuid=<ADMIN_UUID>` 접속
2. 관리자 비밀번호 입력
3. 로그인 후 `/admin` 진입

`univote configure` 또는 `univote qr`를 실행하면 관리자 로그인 QR도 바로 확인할 수 있습니다.

## 3. 게임 정보 준비

행사 전에 관리자 페이지의 `게임/썸네일 준비` 섹션에서 아래를 입력합니다.

- 게임 이름
- 게임 설명
- 참가 부문
- 개발자 목록
- 썸네일 URL 또는 파일 업로드

관련 문서:

- [행사 전 게임 데이터 준비](./game-catalog-setup.md)

## 4. 기명 계정 / 무기명 계정 준비

관리자 페이지의 `사용자 생성`에서 계정을 미리 만들 수 있습니다.

권장 기준:

- `user`: 기명 참가자
- `guest`: 무기명 참가자 / 방문객 / 여분 팔찌
- `admin`: 운영진

무기명 계정은 행사 전에 여유분을 충분히 만들어 두는 것을 권장합니다.

예시 이름:

- `무기명-01`
- `무기명-02`
- `무기명-03`

## 5. 팔찌 발주용 계정 리스트 XLSX 저장

이제 관리자 페이지 상단의 `계정 리스트 (XLSX)` 버튼으로 계정 목록을 액셀 파일로 저장할 수 있습니다.

파일에는 아래 정보가 들어갑니다.

- 이름
- 역할
- 소속
- UUID
- 비밀번호 설정 여부
- 투표 이력 여부
- 여분 팔찌 후보 여부
- 로그인 링크

시트는 보통 아래 3장으로 나뉩니다.

- 전체 계정
- 기명 계정
- 무기명 계정

팔찌 발주나 QR 제작 전에 이 파일을 한 번 저장해 두는 것을 권장합니다.

## 6. 행사 전 마지막 체크리스트

1. 관리자 로그인 성공
2. 게임 카드와 썸네일이 정상 표시됨
3. 기명 계정과 무기명 계정이 충분히 준비됨
4. 여분 guest 팔찌 수량이 넉넉함
5. 계정 리스트 XLSX를 저장해 두었음
