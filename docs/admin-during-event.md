# 행사 중 관리자 운영

이 문서는 행사 도중 운영자가 가장 자주 쓰는 기능만 빠르게 모아둔 문서입니다.

## 1. QR이 안 되는 참가자 대응

### 무기명 계정이라면

- 새 guest 팔찌를 바로 지급하면 되는 경우가 많습니다.
- 필요하면 이름만 수정해서 바로 넘겨도 됩니다.

### 기명 계정이라면

관리자 페이지에서 아래 순서로 처리하세요.

1. 사용자를 검색
2. `여분 팔찌로 교체`
3. 새 guest 팔찌 선택
4. 필요하면 비밀번호도 같이 초기화

자세한 절차:

- [관리자 트러블슈팅 / 현장 이슈 대응](./on-site-playbook.md)

## 2. 비밀번호를 잊어버린 경우

보통은 `비밀번호 초기화`를 먼저 사용하면 됩니다.

초기화 후에는:

- 기존 비밀번호가 사라지고
- 사용자가 QR로 다시 접속했을 때
- 새 비밀번호를 설정하게 됩니다

## 3. 이름이나 동아리 정보가 틀린 경우

관리자 페이지의 `사용자 정보 수정`으로 바로 고칩니다.

이 기능은 아래 상황에서 자주 씁니다.

- 이름 오타
- 동아리 오타
- guest 계정 이름을 현장에서 실제 이름으로 바꿔야 할 때

## 4. 등록이 안 된 참가자가 생긴 경우

`사용자 생성`으로 바로 계정을 만들고 QR을 열어주면 됩니다.

## 5. 현재 투표자 수 보기

관리자 대시보드 상단 카드에서 현재 투표 참여자 수를 바로 볼 수 있습니다.

이 숫자를 보고:

- 아직 참여가 적으면 투표를 독려하고
- 피크 타임인지 확인하고
- 운영 흐름이 잘 돌아가는지 판단할 수 있습니다
